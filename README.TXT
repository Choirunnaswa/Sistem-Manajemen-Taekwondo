# Sistem Manajemen Taekwondo

## 📌 Deskripsi

Sistem Manajemen Taekwondo merupakan project berbasis Java yang dikembangkan menggunakan NetBeans untuk membantu pengelolaan data dan kegiatan dalam organisasi atau tempat latihan Taekwondo.

Project ini dibuat sebagai salah satu project pembelajaran dalam penerapan pemrograman Java dan pengelolaan database.

## 🎯 Tujuan

- Menerapkan konsep pemrograman Java dalam sebuah sistem manajemen.
- Membantu pengelolaan data yang berkaitan dengan kegiatan Taekwondo.
- Menerapkan penggunaan database pada sistem berbasis Java.
- Meningkatkan pemahaman mengenai pengembangan sistem menggunakan Java dan NetBeans.

## ✨ Fitur

- Pengelolaan data Taekwondo
- Pengelolaan data anggota
- Pengelolaan data pelatih
- Pengelolaan kegiatan latihan
- Pengelolaan data menggunakan database
- Pencarian dan pengelolaan data

## 🛠️ Teknologi yang Digunakan

- Java
- NetBeans
- MySQL
- JDBC
## 🚀 Cara Menjalankan Project

1. Pastikan Java dan NetBeans sudah terinstall.
2. Pastikan MySQL sudah berjalan melalui XAMPP atau aplikasi database yang digunakan.
3. Clone atau download repository ini.
4. Buka project menggunakan NetBeans.
5. Pastikan konfigurasi koneksi database sudah sesuai.
6. Import database yang diperlukan ke MySQL.
7. Jalankan project melalui NetBeans.
